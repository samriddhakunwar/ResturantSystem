# Cats

Original cat silhouettes, single ink. Ink: `olive` (#77814f); `cat-walking-charcoal.svg` is the same cat in `charcoal` (#444034) for the one hero cat on a page. Each file's viewBox is cropped tight to the drawing, feet on the bottom edge.

- `cat-walking.svg`: mid-stride facing right, tail hooked up. The OrderStatus progress marker.
- `cat-walking-charcoal.svg`: the hero cat perched on a panel edge, as in the kit.
- `cat-sitting.svg`: upright with the tail wrapped forward. Default placeholder for a cat photo.
- `cat-stretching.svg`: play bow, for empty states ("Nothing here yet").
- `cat-pouncing.svg`: batting upward. Use it for playful cats and the booking confirmation.
- `cat-lying.svg`: loaf with the head up, for "napping" (sold out, closed).
- `cat-grooming.svg`: licking a raised paw, for loading screens.
- `cat-tail-up.svg`: facing left with the tail straight up, to mirror the walking cat on the other side of a layout.
- `cat-crouching.svg`: low and ready to spring, for the 404 page.
