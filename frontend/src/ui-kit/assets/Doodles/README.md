# Doodles

Line drawings at a 2px stroke with round caps in `olive` (#77814f). They decorate panel headers and empty states, and stand in for missing menu photos.

- `steaming-cup.svg`: coffee and tea.
- `leaf.svg`: veg dishes and tea.
- `toy-mouse.svg`, `yarn-ball.svg`: playful accents.
- `fish-bone.svg`: savoury dishes.
- `hearts.svg`: adoption.
- `sparkle.svg` (filled): "New".
- `dot.svg` (filled): a bullet or spacer.
