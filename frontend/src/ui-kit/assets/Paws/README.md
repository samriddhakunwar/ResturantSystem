# Paws

- `paw-print.svg`: one print in `olive`. Use it for step dots and bullets, or repeat it.
- `paw-trail.svg`: five prints walking up and to the right in `olive`. Use it at 35% opacity in page corners.
- `paw-reach.svg`: the kit's tall olive paw reaching up from below, for panel edges.
- `paw-peek-calico.svg`, `paw-peek-ginger.svg`, `paw-peek-black.svg`: full-colour forearms reaching in from the right edge (`ginger`, `calico-tan`, `calico-brown`, `bean-pink`, black #2d2d2d). They are decoration, for the landing and confirmation screens only.
