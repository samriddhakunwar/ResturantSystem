# SocialLinks

Facebook, Instagram and TikTok links for the footer, drawn in one ink like the kit.

- **On cream:** icons in `olive-strong`.
- **On an `olive-dark` footer:** add `wb-social--muted` for cream icons. The kit's very faint cream-on-panel version is decoration only and fails contrast, so it isn't offered.
- Each link needs an `aria-label` with the network's name.
- The marks are the real logos from Simple Icons 15.0.0 (CC0), in the **Social** asset group. They're applied as a CSS mask so they take the ink colour. In React you can use `react-icons` (`FaFacebook`, `FaInstagram`, `FaTiktok`) at 28px instead.
